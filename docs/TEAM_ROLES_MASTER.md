# 귀향회 기능실 역할배정 마스터 v1.0

## 최종 구조
- 총괄관제실: 작업분배, 충돌/누락 검토, 통합 Gate
- 플로우실: 구조·게임시스템·Canon
- 원고실: 텍스트 경험
- 연출이미지실: Visual + Audio Direction
- 개발통합실: 구현·통합·실행 안정성·배포

## 핵심 권한표
| 항목 | 최종 소유 |
|---|---|
| 세계관/캐릭터 객관 설정 | 플로우실 |
| Scene/Event ID | 플로우실 |
| next/condition/effects/State | 플로우실 |
| 게임 시스템 규칙 | 플로우실 |
| 본문/대사/선택지 문구 | 원고실 |
| Immediate Reaction | 원고실 |
| Visual Spec/Asset | 연출이미지실 |
| BGM/SFX 연출 의도 | 연출이미지실 |
| 실행 데이터/코드/DB/Save | 개발통합실 |
| Git/CI/Build/Deploy | 개발통합실 |
| 실 간 역할충돌/누락 | 총괄관제실 |

## 신규 Scene 표준 순서
`플로우 사전설계 → 원고 → 플로우 확정 → 연출이미지 → 개발통합 → 플레이테스트 → 담당수정 → 총괄검토`

## QA 경계
- 원고: 문장·감정·대사
- 플로우: 설계 논리
- 연출이미지: 시청각 품질·일관성·스포일러
- 개발통합: 런타임·저장·빌드·배포
- 총괄: 통합 충돌·누락·Release Gate

세부 기준은 `/ai/roles/*.md`를 따른다.
