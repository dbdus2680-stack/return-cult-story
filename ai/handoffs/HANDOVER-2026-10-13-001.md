# CHAT HANDOVER — 2026-10-13-001

> 목적: 현 총괄관제 채팅에서 다음 총괄관제 채팅으로 운영권을 넘긴다.

## 1. 새 채팅의 역할

새 채팅은 **『귀향회』 AI 협력시스템의 총괄관제실**이다.

사용자는 앞으로 가능하면 이 총괄관제실 하나만 사용한다.
총괄관제실은 요청을 해석해 FLOW / WRITING / VISUAL / DEV로 내부 업무를 분배하고, 결과를 다시 통합해 사용자에게 보고한다.

별도 기능실 채팅은 상시 필수가 아니며, 대량작업이나 특수작업이 필요할 때만 임시로 분리할 수 있다.

## 2. GitHub 운영 원칙

GitHub가 장기기억이자 Source of Truth다.

채팅에서 중요한 결정을 했더라도 GitHub에 반영되지 않은 상태라면 다음 채팅에서 신뢰할 수 있는 장기상태로 간주하지 않는다.

대화 전문을 저장하지 않는다.
다음만 저장한다.

- 현재 상태
- 확정 결정
- 진행 중 작업
- Blocker
- 승인된 산출물
- 다음 행동

## 3. 반드시 읽을 파일

운영체계 도입 전 최신 main 기준으로 다음 변경 이력이 확인되었다.

- PC-001이 고1 신입생 Canon으로 변경/반영
- DAY 1 opening 관련 Scene 반영
- PC1-D01-001 / PC1-D01-002 관련 원고 및 선택 데이터 존재

따라서 새 총괄관제실은 이를 추측으로 확장하지 말고 `MASTER-001` 재인덱싱을 수행해야 한다.

## 9. 사용자에게 다시 물어보지 말아야 하는 것

다음 내용은 GitHub에 이미 정의되어 있으므로 반복 질문하지 않는다.

- 왜 기능실을 나눴는지
- 각 기능실의 기본 역할
- 신규 Scene ID 담당자
- GitHub를 장기기억으로 쓰는지 여부
- 총괄관제 단일채널 운영 여부
- 기본 제작 순서

저장소에서 확인할 수 없는 **새로운 창작 의도나 선택**만 사용자에게 확인한다.
