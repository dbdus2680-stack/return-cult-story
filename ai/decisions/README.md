# DECISION RECORDS

장기적으로 다시 논쟁할 가능성이 있는 **확정 결정만** 기록한다.

파일명 권장: `ADR-###-short-title.md`

## 기록할 것
- 역할/권한 변경
- 데이터 규격 변경
- 게임시스템의 핵심 결정
- 저장 호환성에 영향을 주는 결정
- 대규모 구조 변경
- 반복 제작비에 영향을 주는 연출정책

## 기록하지 않을 것
- 대화 전문
- 단순 아이디어
- 폐기된 안의 장황한 과정
- 오탈자 수정

## 템플릿
```text
# ADR-### 제목
DATE:
STATUS: ACCEPTED / SUPERSEDED
CONTEXT:
DECISION:
RATIONALE:
IMPACT:
AFFECTED FILES:
SUPERSEDES:
```
